## 4. Attractor Dynamics, Synaptic Satiation & Anti-Collapse Habituation

### 4.1 Vesicular Depletion & Attractor Satiation
In recurrent neural network models of neocortex, runaway excitation frequently locks the system into an inescapable attractor basin (e.g., the screen permanently stays on `ДЖУНГЛИ`, and `ГОРА` is extinguished). In biological neocortex, sustained firing of pyramidal ensembles leads to **short-term synaptic depression (STD)** via the depletion of ready-releasable neurotransmitter vesicles [31]:

$$\frac{d R_i(t)}{dt} = \frac{1 - R_i(t)}{\tau_{\text{rec}}} - u_0 R_i(t) r_i(t)$$

NeuroCanvas implements this as **Attractor Satiation**:
```python
dom_idx = int(torch.argmax(self.membrane_potential[:active_count]).item())
self.satiation_counter[dom_idx] += dt
for i in range(active_count):
    if i != dom_idx: 
        self.satiation_counter[i] = max(0.0, self.satiation_counter[i] - dt * 0.5)

# When an attractor dominates continuously past 3.0 seconds, apply vesicular fatigue:
fatigue = float(np.clip((self.satiation_counter[dom_idx] - 3.0) * 0.12, 0.0, 0.45))
effective_mp = self.membrane_potential[:active_count].clone()
effective_mp[dom_idx] -= fatigue
```

When an attractor dominates past 3.0 seconds, vesicular fatigue decreases its effective membrane potential, allowing minority concepts (e.g., `ГОРА`) to resurface and rebalance the canvas.

### 4.2 Autonomous Agent Intention Persistence (Stubbornness)
To prevent agents from instantly capitulating when the visual canvas does not immediately match their intent, the Sequential Probability Ratio Test (SPRT) evidence accumulation rate is calibrated to biological timescales:
$$\Delta S = \eta_{\text{sprt}} \cdot \ln\left( \frac{P_{\text{dominant}} + \epsilon}{P_{\text{target}} + \epsilon} \right) \cdot \left(0.5 + \frac{d_{\text{torus}}}{\pi}\right)$$
where $\eta_{\text{sprt}} = 0.008$ (lowered from 0.040). An agent now requires **8–10 seconds of persistent visual mismatch** before concluding that its current hypothesis cannot be accommodated, ensuring stable agency.

### 5.1 Laminar Push-Pull Oscillations (Superficial $\gamma$ vs. Deep Infragranular $\beta$)
NeuroCanvas implements the laminar oscillatory control architecture validated by Miller, Lundqvist, and Bastos [2, 4]:
* **Superficial Layers (L2/3):** Pyramidal-Interneuron Gamma (PING) oscillations ($30\text{--}100\text{ Hz}$) encode transient, sparse bursts of active memoranda [5]. Spiking is bursty, minimizing metabolic consumption and preventing catastrophic attractor collapse.
* **Deep Layers (L5/6):** Synchronized infragranular $\beta$ oscillations ($15\text{--}30\text{ Hz}$) act as an **inhibitory executive brake**. When deep $\beta$ couples to superficial layers, it terminates gamma bursts and clears active memory contents.
* **Biophysical Gating Equation:**
  $$g(t) = \frac{R_\gamma(t)}{R_\gamma(t) + \kappa R_\beta(t) + \epsilon}$$
  A drop in deep-layer beta disinhibits L2/3 recurrent microcircuits, opening the gate for novel concept entry.

* Each single theta cycle is discretized into **32 temporal phase bins** $\theta_k \in [-\pi, \pi)$.
* **Downbeat Slot 0 Anchor Referencing:** To eliminate zero-frequency baseline drift, cross-spectral density matrices across all 120 electrode pairs are referenced to the initial phase anchor (Slot 0):
  $$\mathbf{\Psi}_{k} = \Im \left( \mathbf{\Phi}_k \odot \mathbf{\Phi}_0^* \right) \in \mathbb{R}^{120}, \quad k \in \{0, \dots, 31\}$$
  Because Slot 0 referenced to itself identically satisfies $\Im(\mathbf{\Phi}_0 \odot \mathbf{\Phi}_0^*) \equiv 0$, the initial downbeat functions as an invariant mathematical origin.

During memory recall and cognitive integration, human neocortex exhibits widespread $\sim 70\text{ ms}$, $89.5\text{ Hz}$ ripples that phase-synchronize across long distances [15].
NeuroCanvas isolates the **Volume-Conduction-Free Corrected Imaginary Phase-Locking Value ($ci\text{PLV}$)** across all 120 electrode pairs [12]:

$$ci\text{PLV}_{i, j} = \frac{\frac{1}{T} \sum_{t=1}^T \Im \left( z_i(t) z_j^*(t) \right)}{\sqrt{1 - \left( \frac{1}{T} \sum_{t=1}^T \Re \left( z_i(t) z_j^*(t) \right) \right)^2}}$$

* **Causal Order Decision Metric:**
  * $\text{Lead} > +0.03 \implies$ Node $A$ leads Node $B$ (Super-ordinate Parent Container: $A \supset B$).
  * $\text{Lead} < -0.03 \implies$ Node $B$ leads Node $A$ (Sub-ordinate Child Component: $B \supset A$).
  * $|\text{Lead}| \le 0.03 \implies$ Synchronous Co-occurrence (Peer Coexistence: $A \parallel B$).

### 5.4 High-Dimensional Orthogonal Plasticity & True LTM Selectivity Ratio
Each `BrainSubject` maintains a **4,096-column CUDA Cortical Macrocolumn Sheet** with $1.95\%$ SDR sparsity ($k = 80$ active columns):
1. **Hebbian Long-Term Potentiation (LTP):**
   $$\mathbf{W}_{\text{target}} \leftarrow \text{clamp}\left( \mathbf{W}_{\text{target}} + \eta \cdot \mathbf{C}(t), 0.01, 1.0 \right)$$
2. **Anti-Hebbian Long-Term Depression (LTD):**
   $$\mathbf{W}_{\text{competitor}} \leftarrow \text{clamp}\left( \mathbf{W}_{\text{competitor}} - \eta \cdot \lambda_{\text{LTD}} \cdot \mathbf{C}(t), 0.01, 1.0 \right)$$
3. **Contrastive Cosine Selectivity Metric:**
   To prevent catastrophic weight saturation where all classes falsely report $100\%$, memory consolidation is measured through pairwise normalized cosine orthogonality:
   $$S_{i, j} = \frac{\mathbf{W}_i \cdot \mathbf{W}_j}{\|\mathbf{W}_i\|_2 \|\mathbf{W}_j\|_2}$$
   $$\text{Selectivity}_i = \text{clamp}\left( \frac{0.85 - \max_{j \neq i} S_{i, j}}{0.50}, 0.0, 1.0 \right) \times 100\%$$
   If synaptic weights for two concepts overlap completely ($S_{i, j} \approx 1.0$), selectivity is mathematically **0.0%**. True 100% retention is achievable only when weights achieve biological orthogonality ($S_{i, j} \le 0.35$).

### 5.5 Sequential Real-Time Calibration & Strict Quality Gate
During calibration, concepts are presented in a deterministic sequential queue:
$$\text{Queue: } [ \text{QUEUED} ] \longrightarrow [ \text{LEARNING} ] \longrightarrow [ \text{SAVED} ] \quad (\ge 75\%)$$

* **Real-time Inspection:** The UI displays the live Fisher's $d'_k$ and LTM retention percentage for every concept simultaneously.
* **Strict Quality Gate:** The engine enforces that calibration **cannot exit** until every single concept reaches the statistical criterion ($d'_k \ge \text{calib\_sigma}$ and $\text{LTM}_k \ge 75\%$). Premature release on partial averages is mathematically blocked.

## 6. Hardware Execution, Asynchronous Time-Warp Reprojection & Fast Launch

### 6.1 Asynchronous Time-Warp Reprojection (Sub-200ms Latency Compensation)
Because diffusion backends (LCM, SD-Turbo) require $150\text{--}250\text{ ms}$ per inference step while the OpenGL/Pygame display updates at **60 FPS** ($16.6\text{ ms}$), naive frame blending creates visual rubber-banding (the newly generated frame overwrites 200 ms of real-time camera travel, snapping the image back to the past).

NeuroCanvas implements **Time-Warp Asynchronous Reprojection**:
1. At dispatch time $t_0$, the worker captures the avatar's kinematic state $(x_0, y_0, \theta_0)$.
2. Upon return of the completed tensor at $t_1$, the worker reads the current avatar state $(x_1, y_1, \theta_1)$ and computes the delta displacement:
   $$\Delta x = -(x_1 - x_0) \cdot W \cdot 0.12, \quad \Delta \text{zoom} = 1.0 + (y_1 - y_0) \cdot 0.18, \quad \Delta \theta = -(\theta_1 - \theta_0) \cdot 10.0$$
3. The newly generated image is re-projected via an affine transform $M(\Delta \theta, \Delta \text{zoom}, \Delta x)$ **before** temporal frame blending:
   $$\mathbf{I}_{\text{canvas}} \leftarrow 0.25 \cdot \mathbf{I}_{\text{canvas}} + 0.75 \cdot \text{WarpAffine}\left( \mathbf{I}_{\text{diffusion}}, M \right)$$
Camera flight remains completely continuous and buttery smooth without tearing or backward jitter.

### 6.2 Decoupled Non-Blocking Visual CLIP Teacher (1-Second Instant GUI)
The heavy Vision-Language model (`openai/clip-vit-large-patch14`, $1.7\text{ GB}$) is initialized inside an isolated daemon thread. The Pygame viewport and LSL streams initialize immediately, allowing the application window to open in under **1.0 second**. While the background thread loads CLIP weights, the classifier returns uniform priors without blocking the 60 FPS render loop.

### 6.3 Direct-Memory POSIX IPC & FreeEEG16 Hardware Bridge
* **Zero CPU Recomputation:** PAC trajectory tensors $\mathbf{\Psi}_{32 \times 120}$ and 4D kinematic variables are evaluated directly within PyTorch CUDA tensors in `GPU_Daemon_Process`.
* **Ring-Buffer Purging (`max_samples=8192`):** `inlets[i].pull_chunk` pulls all accumulated samples and slices the trailing `[-BUF_SIZE:]`, locking processing windows to real-time regardless of background load.
* **Full-Duplex BLE-to-LSL Bridge:** `direct_ble_to_lsl.py` connects to FreeEEG16 hardware via Bleak with per-channel saturation diagnostics ($299,000\text{ }\mu\text{V}$ threshold) and dynamic auto-gain attenuation.
