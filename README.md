## 3. Thousand Brains Project (`tbp.monty`) & Compositional Consensus Architecture

### 3.1 Decoupled L4 Learning Modules vs. L2/3 Consensus Docking Layer
1. **L4 Granular Layer (Local Learning Modules):** Each cortical region maintains its own 4,096-column canonical HTM sheet and private synaptic permanence matrix $\mathbf{W}_{\text{local}} \in \mathbb{R}^{N_{\text{nodes}} \times N_{\text{concepts}} \times 32 \times 4096}$, learning local sensory-at-location representations independently.
2. **L2/3 Supragranular Layer (Consensus Docking Layer):** Columns communicate via long-range horizontal excitatory axons in layer 2/3. Lateral coincidence detection aggregates evidence across columns to form the **Consensus SDR (СДР Стыковки)** ($k = 80$ out of 4,096).

### 3.2 Topological Relational Operators
Columns evaluate four topological affordance hypotheses relative to the dominant world:
1. **`SUPER_PARENT` ($A \supset W$):** Concept $A$ has a higher spatial scale prior (e.g., `КОСМОС ⊃ ПЛАНЕТА`).
2. **`EMBED_INTO` ($A \rightarrow W$):** Concept $A$ embeds into the world's geometry (e.g., `ДЖУНГЛИ ➔ ГОРА`).
3. **`PEER` ($A \parallel W$):** Equal scale lateral coexistence (e.g., `ОКЕАН ∥ ДЖУНГЛИ`).
4. **`SUB_CHILD` ($A \prec W$):** Grounding foundation (e.g., `ГОРА ⊂ ЗАМОК`).

### 3.3 Hemispheric Latent Partitioning
To combine shape and style without latent destruction, NeuroCanvas applies hemispheric dimension-splitting with balanced variance normalization:

## 4. Biophysical & Mathematical Foundations

### 4.1 100% GPU-Accelerated LTM Selectivity
To eliminate CPU-GPU pipeline stalls (which cause catastrophic FPS drops as concepts scale), pairwise cosine orthogonality is evaluated as a single batched tensor operation on CUDA:
$$\mathbf{C} = \text{bmm}\left(\widehat{\mathbf{W}}, \widehat{\mathbf{W}}^T\right) \in \mathbb{R}^{N_{\text{nodes}} \times K \times K}$$
$$\text{Selectivity}_i = \text{clamp}\left(\frac{0.85 - \max_{j \neq i} C_{i, j}}{0.50}, 0.0, 1.0\right) \times 100\%$$

$$ci\text{PLV}_{i, j} = \frac{\frac{1}{T} \sum_{t=1}^T \Im \left( z_i(t) z_j^*(t) \right)}{\sqrt{1 - \left( \frac{1}{T} \sum_{t=1}^T \Re \left( z_i(t) z_j^*(t) \right) \right)^2}}$$
* $\text{Lead} \ge +0.03 \implies A \supset B$ (`SUPER_PARENT` container).
* $\text{Lead} \le -0.03 \implies B \supset A$ (`SUB_CHILD` foundation).
* $|\text{Lead}| < 0.03 \implies A \parallel B$ (`PEER` coexistence).

### 4.3 Overlap-Selective Lateral LTD (Oja's Rule)
Prevents catastrophic forgetting during sequential learning:
$$\Delta \mathbf{W}_{\text{target}} = \eta \cdot (\mathbf{S}(t) - \mathbf{W}_{\text{target}})$$
$$\Delta \mathbf{W}_c = -\eta \cdot \lambda_{\text{LTD}} \cdot (\mathbf{S}(t) \odot \mathbf{W}_c) \quad (\forall c \neq \text{target})$$
